# Credits

The six bundled backgrounds (mountains, forest, sea, sunset, space and abstract) were generated for this project with OpenAI image generation on 2026-10-22. The images were converted to optimized JPEG files and separate thumbnails. No third-party photos or external image URLs are included. The project distributes these backgrounds under the same MIT license as the plugin.

`assets/logoB.png` is an unchanged local copy of the Textmediary logo published at `https://textmediary.com/source/logoB.png`. It is a Textmediary brand asset, not part of the plugin's MIT-licensed code or backgrounds.

Roundcube and its Elastic skin are separate projects and are not bundled or modified here. The plugin uses their public plugin and JavaScript APIs. The palette glyph comes from the icon font already bundled with Elastic.
